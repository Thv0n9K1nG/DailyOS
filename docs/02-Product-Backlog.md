## User Stories

### PB-001 Dashboard

**As a user**, I want to see today's overview immediately after opening the application so that I know what to focus on.

Acceptance:

- Show today's tasks
- Weekly progress
- Quick timer
- Calendar summary
- Count down board.

### PB-002 Calendar

As a user, I can browse every day of the year and open a day's detail page.

Acceptance:

- Correct Gregorian calendar
- Month navigation
- Day detail

### PB-003 Todo Management

As a user, I can create, edit, complete, archive and delete tasks.

Acceptance:

- CRUD
- Priority
- Deadline
- Completion history

### PB-004 Daily Detail

Shows completed tasks, notes, sessions and statistics for a selected day.

### PB-005 Tomorrow Planning

Prepare tomorrow's task list and automatically move it into today's tasks.

### PB-006 Stopwatch

Track focus sessions and save duration.

### PB-007 Pomodoro

25/5 configurable focus timer.

### PB-008 Habit Tracker

Track recurring habits with streak calculation.

### PB-009 Goal Tracker

Long-term goals with progress bars.

### PB-010 Daily Notes

Markdown notes attached to a calendar day.

### PB-011 Mood Tracker

Record mood once per day.

### PB-012/013/014 Analytics

Weekly, monthly and yearly dashboards including GitHub-style heatmap.

### PB-015 Statistics

Charts:

- completed tasks
- focus hours
- streaks
- completion rate

### PB-016 Search

Search tasks, notes and habits.

### PB-017 Tags

Categorize tasks.

### PB-018 Recurring Tasks

Daily/weekly/monthly recurrence.

### PB-019 Backup

Backup and restore SQLite database.

### PB-020 Settings

Theme, preferences and data management.

### PB-021 Date Countdown

Adding and displaying a board including countdown to key dates.
