# 04 - Use Case

## Actor
User

### UC-001 Launch Application
Open app, load SQLite, display dashboard.

### UC-002 Create Task
Create and save a task.

### UC-003 Complete Task
Mark task complete, save history, refresh dashboard.

### UC-004 View Calendar Day
Show tasks, notes, sessions and habits for selected day.

### UC-005 Tomorrow Planning
Create tomorrow's tasks; import automatically next day.

### UC-006 Focus Session
Start timer, stop timer, save duration.

### UC-007 Habit Tracking
Check habit and update streak.

### UC-008 Countdown
Set title and target date; dashboard displays remaining days.

### UC-009 Backup
Export SQLite database.

### UC-010 Analytics
View weekly, monthly and yearly statistics.
