# 03 - User Flow

## Navigation

Launch App -> Dashboard

- Calendar -> Daily Detail
- Tasks -> CRUD -> Complete
- Tomorrow Planning
- Habit Tracker
- Stopwatch/Pomodoro
- Analytics
- Countdown
- Settings

## Flows

1. Create Task: Dashboard->Tasks->New->Save.
2. Complete Task: Task->Complete->History updated.
3. Tomorrow Planning: Add tasks->Next day import.
4. Calendar Review: Calendar->Date->Daily Detail.
5. Focus Session: Start->Stop->Save.
6. Habit Check-in.
7. Countdown: Set target date->Dashboard shows remaining days.
8. Backup: Settings->Backup.
